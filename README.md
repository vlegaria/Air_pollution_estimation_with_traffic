## Figures and table generation

The script `Figures_maker.py` generates all the figures presented in the article, with the exception of the map showing the monitoring station locations; the correlation matrices presented in the Supplementary Material, which are generated using correlation_matrices.py; and **Figure SM1**, which is generated using Validation_OpenWeather_data.py.

The script `Tables_maker.py` generates the CSV files for all the tables presented in the article and the Supplementary Material, with the following exceptions: **Table 2**, which provides information on the pollutants measured at the neighbouring monitoring stations; **Table SM2** in the Supplementary Material, which reports the hyperparameter search space used for the optimisation of each machine-learning model; and **Tables 4–7**, which are generated using Tables_ridge_vs_ML.py.


To run these scripts, the following folders and files are required:

- The datasets stored in the `Datasets_to_train` folder.
- The `nested_CV` folder, containing the trained models and their evaluation metrics, located inside the `Datasets_to_train` folder.
- The IDW interpolation results stored in the interpolation_results folder.
- The OK interpolation results stored in the interpolation_results_chronological_selection folder.
- The cross-site validation results stored in the validation_results folder.
- The statistical test results stored in the block_bootstrap_results folder.

These results are generated by the scripts provided in this folder, which are sequentially numbered according to their execution order and implement the methodology described in the article.
